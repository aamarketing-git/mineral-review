# 오륜미네랄 체험단 앱

토스 디자인 레퍼런스 기반의 1박 2일(28시간) 미네랄 체험단 모집·진행·완료 보고 통합 폼.
모든 데이터는 Google Sheets에 실시간으로 적재됩니다.

## 📦 구성 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 체험단이 보는 메인 앱 (신청 / 완료 보고 / 글쓰기 가이드 3개 탭) |
| `google-apps-script.gs` | 구글 시트에 데이터를 받아 적재하는 백엔드 스크립트 |
| `README.md` | 본 문서 |

## 🚀 설정 순서 (10분 소요)

### 1단계. 구글 시트 만들기
1. https://sheets.new 에서 새 시트 생성
2. 시트 이름은 자유 (예: "오륜미네랄 체험단 운영")

### 2단계. Apps Script 연결
1. 메뉴 → **확장 프로그램** → **Apps Script**
2. 기본 코드 전체 삭제
3. `google-apps-script.gs` 내용을 전체 복사 → 붙여넣기
4. 저장 (Ctrl+S 또는 디스크 아이콘)

### 3단계. 웹 앱으로 배포
1. 우측 상단 **배포** → **새 배포**
2. ⚙️ 아이콘 → **웹 앱** 선택
3. 설정:
   - **설명**: `오륜미네랄 체험단 폼`
   - **다음 사용자로 실행**: `나 (본인 계정)`
   - **액세스 권한**: `모든 사용자` ← 익명도 제출 가능하게
4. **배포** 클릭 → 권한 승인 (Google 계정 → "고급" → "안전하지 않은 페이지로 이동")
5. 발급된 **웹 앱 URL** 복사

### 4단계. index.html에 URL 연결
`index.html` 파일 안 아래 부분을 찾아서 URL을 교체:

```javascript
// ============================================
// CONFIG: 여기에 Google Apps Script Web App URL을 넣어주세요
// ============================================
const GAS_URL = "https://script.google.com/macros/s/PASTE_YOUR_DEPLOYMENT_ID_HERE/exec";
```

### 5단계. 배포
원하는 어디든 호스팅 가능합니다:
- **간단**: GitHub Pages, Netlify Drop, Vercel (`index.html` 파일 하나만 끌어다 놓기)
- **자체 도메인**: 카페24, 가비아, AWS S3 등
- **로컬 테스트**: 더블클릭으로 브라우저에서 바로 열어도 동작합니다

## 🎨 디자인 커스터마이즈

`index.html` 상단 `:root` 블록에서 색상 조정:

```css
:root {
  --toss-blue: #3182f6;       /* 메인 컬러 - 브랜드 컬러로 교체 가능 */
  --toss-blue-soft: #e8f3ff;  /* 메인 컬러의 옅은 버전 */
  --bg-soft: #f9fafb;          /* 배경색 */
  ...
}
```

오륜미네랄 브랜드 색상이 있다면 `--toss-blue` 값만 바꿔도 전체 톤이 자연스럽게 변합니다.

## 🛠 자주 묻는 문제

**Q. 폼 제출은 되는데 시트에 데이터가 안 쌓여요**
- Apps Script 코드를 수정한 뒤 **반드시 "배포 관리 → 연필 → 새 버전"으로 재배포**해야 반영됩니다. 신규 배포가 아니라 같은 URL을 유지하려면 이 방식이 필수입니다.
- 액세스 권한이 "모든 사용자"인지 다시 확인하세요.

**Q. CORS 오류가 떠요**
- 코드가 `mode: "no-cors"`를 사용하므로 브라우저에서 응답을 읽지는 못하지만, 시트에는 정상 기록됩니다. 정말로 오류가 나는지 직접 시트를 확인해 보세요.

**Q. 중복 신청을 막고 싶어요**
- `google-apps-script.gs`의 `writeApply` 함수 안에 휴대폰 번호 중복 체크 로직을 추가하면 됩니다. 필요하면 요청 주세요.
